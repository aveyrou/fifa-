# FUT Packs — открытие паков в стиле FIFA 26

Самодостаточный веб-сайт (HTML + CSS + JS, без сборки и зависимостей):
- 5 видов паков (Bronze → Ultimate), 7 редкостей карт (Bronze, Silver, Gold, Rare Gold, TOTW, Hero, Icon)
- Анимация открытия: переворот карточки, вспышка для редких
- Инвентарь с фильтром по редкости и сортировкой
- Продажа карточек (одним кликом, выделением, или всех дубликатов) — монеты возвращаются
- Сохранение прогресса в `localStorage`
- Адаптивная вёрстка для телефонов

## Файлы

- `index.html` — разметка
- `styles.css` — стили (включая мобильную адаптацию)
- `data.js` — игроки, редкости, паки, расчёт цены продажи
- `app.js` — состояние, рендер, логика паков и продаж
- `README.md` — этот файл

## Как запустить

### Вариант 1 — двойным кликом
1. Распакуйте архив `fut-packs.zip` в любую папку.
2. Откройте файл `index.html` в браузере (Chrome / Safari / Firefox / Edge).
   В Windows — двойной клик. В macOS — правый клик → «Открыть в…».
3. Готово. У вас 5 000 стартовых монет.

### Вариант 2 — локальный сервер (рекомендуется для мобильного тестирования)
Если запустить как локальный сервер, можно открывать сайт со смартфона по Wi-Fi.

```bash
# в папке с проектом
python3 -m http.server 8080
# или, если есть Node.js:
npx serve -l 8080
```
Затем откройте `http://<ip-компьютера>:8080` со смартфона в той же сети.

### Вариант 3 — выложить онлайн
Файлы статические, поэтому подойдёт любой бесплатный хостинг: GitHub Pages, Netlify Drop, Vercel, Cloudflare Pages. Просто загрузите содержимое папки.

## Как играть

1. **Магазин** — выберите пак, нажмите «Открыть». Списываются монеты, запускается анимация.
2. **Открытие** — нажимайте «Открыть следующего» или клик по карточке, чтобы перевернуть. Кнопка «Раскрыть все» — пропустить анимации.
3. **Инвентарь** — все ваши карточки. Фильтры по редкости, сортировка по рейтингу / времени / редкости. Кнопка «Продать» прямо на карточке — быстрая продажа.
4. **Продажа** — кликайте по карточкам, чтобы выделить (синий контур). Внизу — сумма. Кнопка «Продать всех дубликатов» оставляет по одной копии каждого игрока.
5. **Монеты** — отображаются в правом верхнем углу. Сбросить прогресс можно ссылкой внизу страницы.

## Шансы

Шансы редкостей внутри каждого пака указаны на самой карточке пака в виде чипов.
Внутри `data.js`:
- `RARITIES.<rarity>.weight` — базовый «вес» редкости (не используется напрямую; реальные шансы заданы в каждом паке).
- `PACKS.<pack>.table` — таблица шансов в процентах для конкретного пака.
- `PACKS.<pack>.guarantees` — гарантированные дропы (например, минимум 1 Rare Gold в Premium).

## Кастомизация

- **Добавить игрока:** допишите объект в массив `PLAYERS` в `data.js`. Полей `id`, `name`, `club`, `nation`, `pos`, `rarity`, `ovr` достаточно.
- **Изменить цены продажи:** функция `sellPrice(player)` в `data.js`.
- **Поменять шансы:** правьте `PACKS.<id>.table` и `guarantees`.
- **Стартовые монеты:** в `app.js`, `defaultState.coins`.
- **Цвет редкости:** переменные CSS `--r-<rarity>-1/2/text` в `styles.css`.

## Поддерживаемые браузеры

Последние версии Chrome / Safari / Firefox / Edge (desktop и mobile). Не требует интернета после открытия — всё работает локально.
